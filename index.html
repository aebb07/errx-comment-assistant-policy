Privacy Policy

How ERRX Comment Assistant processes Instagram comments on @errx.vu.

Last updated: October 21, 2026

Data collectedService providersData deletionContact

1. Operator

ERRX Comment Assistant is an independently operated, locally run Instagram comment-management tool used by the operator of the Instagram Creator account @errx.vu ("the Operator"). It is not a product of Meta or Instagram. Privacy contact: aebbp07@gmail.com.

2. Information processed

When access is authorized through Instagram's API, the tool can retrieve and locally store:

  • Instagram usernames and the text of comments on @errx.vu posts;
  • post and comment IDs, timestamps, and limited post-caption context;
  • reply drafts, published reply IDs, review notes and processing status;
  • any account usernames the Operator designates for manual review.

The Operator stores access tokens and API keys in a local configuration file. The tool does not require access to direct messages or Instagram passwords.

3. Purposes

Information is used to find and organize older and newer Instagram comments, generate relevant reply drafts, support human review, prevent duplicate replies, and publish replies through Instagram's API when explicitly enabled. Processing and privacy rights are handled in accordance with applicable law.

4. Service providers

The tool obtains Instagram information through Meta's Instagram API. If the Operator requests an AI-generated reply, relevant comment text, username, limited post context and recent response drafts may be sent to OpenAI's API to generate a response. This website is hosted by GitHub Pages, which may process basic technical visitor information. The Operator does not sell comment data or use the tool to profile people for advertising.

5. Storage and retention

Retrieved comments and drafting status are stored in a SQLite database on the Operator's computer. The current prototype has no automatic retention period; records remain until manually deleted or the local database is removed. Local credentials should not be published or uploaded to this website. Backups, if any, are managed by the Operator. The tool's OpenAI API calls use store=false, but this does not mean providers perform no other processing or retention under their policies.

6. Your choices and requests

You can manage your own Instagram comments through Instagram. You may also request access to, correction of, or deletion of the data about you in this tool's local records, or raise a concern about processing, where applicable. The Operator may request reasonable information to locate the relevant record or verify a request; do not send passwords or login codes.

7. Deleting data

For instructions, see User Data Deletion. Deleting a locally stored record does not remove an original Instagram comment or automatically reverse a reply already published on Instagram.

8. Updates

We may update this notice when the assistant's functionality, providers or practices change. The update date above identifies the current published notice.

9. Contact

For questions and privacy or deletion requests, email aebbp07@gmail.com.
